## Воспроизведение

```bash
uv sync
uv run python -m app.cli train
uv run python -m app.cli evaluate --holdout 2026-01
uv run python -m app.cli evaluate --holdout 2025-02
```

При сохранённом кэше команды не требуют сети, LLM или ключей. `train` заменяет
production-модель; `evaluate` обучает отдельную модель строго до проверяемого
месяца и заменяет соответствующий JSON, не production pickle.

| Команда | Измеренное время wall clock |
|---|---:|
| `train` | 30,43 с |
| `evaluate --holdout 2026-01` | 43,11 с |
| `evaluate --holdout 2025-02` | 152,78 с |

Время измерено `/usr/bin/time -p` на рабочем Mac команды при параллельной работе
других процессов. Это один запуск каждой команды, не аппаратный бенчмарк.

### Почему нужна нормализация признаков

На одном pickle и одинаковой погоде Windows и macOS давали разные ветки GBM:
разница косинуса направления ветра на один ULP меняла прогноз турбины с 0,6265
на 0,7166. Это воспроизведено на Mac сдвигом только `dir_cos` на один ULP.
Округляются входные признаки в общей функции `add_features`, а не выходной
прогноз; модель после изменения переобучена. В метаданных pickle записано
`feature_decimals=12`.

Для всех 2 296 февральских строк нового артефакта сдвиг результатов `sin`, `cos`
и интерполяции на один ULP в обе стороны сохранил прогнозы побитно. Это локальная
проверка чувствительности; отдельная проверка нового артефакта на Windows и
Linux фиксируется в `TESTING.md` после её завершения.

## Что именно оценивается

Цель станции — среднее наблюдений двух равномощных турбин, нормализованное к 1.
Если неизвестна хотя бы одна турбина, метка станции отсутствует; известная
индивидуальная метка остаётся для модели этой турбины. Медиана станции обучается
отдельно, поэтому не обязана совпадать со средним прогнозных медиан турбин.

- `MAE = mean(abs(prediction − observation))` — доля номинала.
- `nMAE = 100 × MAE` — процент номинала, не процент фактической выработки.
- `skill = 1 − MAE_model / MAE_baseline` — относительное снижение ошибки.
- `coverage` — доля оценённых пар, где факт внутри p10–p90; `mean_width` — средняя
  ширина этого интервала станции, в долях номинала.
- `24h` — опережение 0–23 ч; `48h` — 24–47 ч. `all` объединяет оба диапазона.
  Один целевой час может встречаться в двух выпусках, поэтому число пар и число
  уникальных часов различаются.

| Период | Выпуски | Пары D+1 | Пары D+2 | Пары всего | Уникальные часы |
|---|---:|---:|---:|---:|---:|
| Январь 2026 | 31 | 744 | 720 | 1 464 | 744 |
| Февраль 2025 | 28 | 666 | 642 | 1 308 | 666 |

В феврале 2025 нет наблюдений обеих турбин за 28.02, 06:00–11:00 UTC
(11:00–16:00 Алматы). Эти шесть часов исключены, не заполнены вымышленным фактом.

## Стоимость и вклад оркестратора

Сценарная стоимость умножает все абсолютные отклонения заявки D+2 на мощность
5 МВт, цену 22,68 тг/кВт·ч и коэффициент 0,3. Освобождение внутри ±5 % и
взаимозачёт не моделируются; режим фактического договора станции неизвестен.
Это условная верхняя оценка по **720 январским и 642 февральским часам**,
не счёт и не измеренная экономия. Первые сутки месяца в D+2 не покрыты.
GBM: 3,88/3,84 млн тг; кривая: 5,10/4,48; персистентность: 7,44/7,81.

ΔMAE для пересчёта считается на затронутых часах; затем эффекты усредняются
по выпускам. Это не разность агрегированных MAE всей таблицы. Интервал пересчёта
включает ноль: устойчивое улучшение на новых периодах не доказано. Bootstrap
использует выпуски как блоки, но соседние выпуски разделяют целевые часы;
выводы по одному месяцу ограничены. В обычном январе запасная модель,
смена источника и флаг дрейфа не сработали.
