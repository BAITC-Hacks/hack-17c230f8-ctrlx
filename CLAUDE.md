## Только для Claude Code
В этом репо правила ниже перекрывают `~/.claude/CLAUDE.md`:
- Коммиты прямо в `main` — ок (5 часов, без PR).
- Push — только через `scripts/checkpoint.sh "…"`, отдельно не спрашивай. Голый `git push` не делай.
- Dev-сервер можно запускать самому: один, на фиксированном порту (web 3000 / py 8000), после проверки — погасить.
- Prod-деплой — только `scripts/deploy.sh` и только когда лид попросил.
- Новые зависимости — только после ОК лида (он владелец lockfile).
- Новые файлы: код, тесты, `docs/*`, `data/*`, `scripts/*`. Прочее в корне — только по просьбе.
- Скиллы проекта (вызываются вручную): `/kickoff`, `/checkpoint`, `/critics`, `/ship`; `/grilling` — прожарка идеи или плана раундами вопросов с рекомендованными ответами. Для любого UI — `ui-craft` (облик + движение + тексты; ревью UI — таблицей Before | After | Why).
- UI проверяй во встроенном браузере приложения: `read_page` / `find` → клик по `ref`, не по координатам; скриншот — только для визуальной оценки (`ui-craft`) или по просьбе.
- Строка «⏱ …» в начале запроса — время до фриза и дедлайна, твоя роль и зона: подгоняй объём работы под время и не выходи за зону. Под ней — «💬» новые сообщения команды: ответь или учти их в работе.
- Ждёшь ответа или результата от команды (контракт, эндпоинт) — запусти `scripts/msg.sh wait` в фоне (run_in_background): когда придёт сообщение, ты проснёшься сам. Пока ждёшь — делай свою часть на моках.
